# KA ESPORTS — Glicko-2 Ranking System for Mario Kart 64

Sistema de ranking basado en Glicko-2 para torneos de Mario Kart 64. Calcula ratings, desviaciones y volatilidades de jugadores a partir de resultados de partidas.

## Tech Stack

- **Frontend:** Vanilla JS ES Modules, CSS tokens
- **Backend:** Google Apps Script
- **Hosting:** GitHub Pages

## Cómo empezar

```bash
npm install
npm run dev
```

(Requiere `build.mjs` para el entorno de desarrollo.)

## Scripts disponibles

- `npm test` — Ejecuta los tests
- `npm run build` — Compila el proyecto
- `npm run dev` — Inicia servidor de desarrollo
